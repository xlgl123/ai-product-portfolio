# AI 产品作品集

面向 AI 产品与产品体验方向的个人作品集，包含项目介绍、界面展示与产品设计思考。

项目涵盖秘密基地、OB 自适应版本、MioStudio、衡契、片羽、星澪，以及 Notion、语音、桌面机器人与设备连接工具合辑。

## 预览

在此目录启动静态网页服务器后打开首页。网站可部署在支持静态文件的托管平台，也可绑定自定义域名。

## 来源

- 秘密基地基于 AionsHome 二次开发。
- OB 自适应版本基于 Ombre Brain 二次开发。
- AlingShell 固件基于 M5Stack StackChan 二次开发。
- MioStudio 使用 Animal Island UI，组件库许可为 CC BY-NC 4.0。

各页面保留对应上游链接与来源说明。此仓库为作品集展示页面，产品源码分别维护。
